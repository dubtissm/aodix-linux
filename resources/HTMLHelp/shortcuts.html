Aodix – Keyboard and Mouse Shortcuts

All shortcuts of Aodix for Linux 4.2.1.x. new marks additions and changes of the Linux version. Ctrl = Control key. The original quick reference also explains the event syntaxes.

Transport and modes

SpacePlay / Stop
F1Record events on/off
F2Write automation on/off
F3Cycle (loop) on/off
F4Live recording on/off
F5Stop-wrap on/off
F6Step (cursor advances after entering) on/off
F7Overwrite on/off
F8Switch sequencer / routing view
F9Event / pattern entry mode
F10Open the plugin editor of the current instancenew

Edit settings

Ctrl+1 / 2Quantization smaller / larger
Ctrl+3 / 4MIDI channel down / up
Ctrl+5 / 6Keyboard octave down / up
Ctrl+7 / 8Note pre-release −5% / +5% (on a 5% grid, 0–95%, per pattern)new
Shift+Q / EZoom out / innew
Ctrl+mouse wheelZoom
Ctrl+,Configuration dialog
Ctrl+F12Reload skin and color theme from disk (for skin and theme authors)new

Moving around in the sequencer

↑ ↓Cursor one quantization step up / down
← →Previous / next data column (into the next track)
Mouse wheelCursor up / down by the quantization
Ctrl+↑ / ↓To the previous / next event in the track
Page Up / Page DownOne bar up / down
Ctrl+Page Up / Page DownTo position 000:0 / to the last event of the pattern
Home / EndTo the start / end marker
Tab / Shift+TabNext / previous track
Ctrl+← / →8 tracks left / right
Double-click (left half of a track)Cursor to this position
Middle mouse button + dragDrag the sequencer: vertically (faster when zoomed out) and by whole tracksnew
Drag the position columnScroll; snaps to the grid unless Ctrl is held

Patterns

Numpad + / −Next / previous pattern
Shift+D / ANext / previous patternnew
Shift+W / S16 patterns forward / back (up to FF / down to 00)new
Enter on a pattern callGo to the called pattern
Ctrl+EnterBack to the previous pattern

Entering events

Piano keysNotes: lower octave on the bottom letter row (Z…M, QWERTZ Y…M), upper octave on Q…P, sharps on the row above; layout in the configuration
1Write a jump event
EnterWrite a MIDI program change (current program of the instance)
0…9, A…FHex values in the data columns of an event
DelDelete events at the cursor (routing view: unload the instance)
Insert / BackspaceInsert / remove space in the track (following events move)
Ctrl+Insert / BackspaceThe same across all tracks
+ / Ctrl++Resize the previous event(s) to the cursor (track / all tracks)

Selection (block)

Drag in the left half of a trackSelect a block
Ctrl+B / EBlock start / end at the cursor
Ctrl+ASelect exactly the events of the patternnew
Ctrl+LStart and end marker on the selection, cycle on, cursor to the start markernew
Ctrl+C / X / VCopy / cut / paste
Ctrl+ZUndo
Ctrl+F1 / F2Value at the cursor −1 / +1 for the whole block (transpose, velocity …)
Ctrl+QQuantize the notes of the block
Ctrl+RRandomize the value at the cursor in the block
Ctrl+IInterpolate the value at the cursor across the block

Events with the mouse (right half of an event)

DragMove the event; an event of the selection moves the whole selectionnew
Ctrl+dragDrag a copy (of the event or of the whole selection)new
Ctrl held when droppingDrop off the grid; release Ctrl before dropping to snap to the grid
Shift while draggingKeep the position (change only the track)
Drag the bottom edgeChange the length
Double-clickDelete the event

Tracks and markers

Ctrl+MMute the track
Ctrl+. or Ctrl+Shift+MSolo the tracknew
Ctrl+Home / EndSet the start / end marker at the cursor
Double-click in the timeline columnCreate / delete a marker
Ctrl+double-click in the timeline columnCreate / delete the stop marker

Plugin instances

Numpad / / *Previous / next instance
Ctrl+9 / 0Previous / next instancenew
Double-click an empty slotPlugin library (load a plugin)
Double-click an instanceOpen its editor
F10Open the editor of the current instancenew
Ctrl+click on a used slotCenter the routing view on the instance
m / b buttonsMute / bypass; a bypassed plugin is not processed (no cpu load)new

Routing view

Double-click on an empty spotLoad a plugin there
Drag on an empty spot / middle mouse button + dragMove the view (middle button: anywhere)new
Drag an instanceMove it
Ctrl+drag an instanceDrag a copy (same plugin and settings, no wires)new
Drag from an output pin to an input pinDraw a wire
Drag the arrow of a wireGain of the wire
Double-click the arrow of a wireDelete the wire
Ctrl+click / double-click on an output pin or arrowDraw / delete all wires of the instance
Click on a master input / output pinAssign the audio port
DelUnload the selected instance

Values in boxes and knobs

Click + move the mouseChange the value
Ctrl+click + moveFine adjustment
Double-click (pre-release, zoom …)Default value

Files

Ctrl+NNew project
Ctrl+OOpen project (starts in the project folder of the configuration)
Ctrl+SSave
Ctrl+Shift+SSave as
Ctrl+WBounce (render to a WAV file)
